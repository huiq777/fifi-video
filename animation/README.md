# animation

Finished films made by AI, kept here as showcases. Each folder holds one film's full source code or the prompt behind it.

**These are not part of the fifi-video toolkit.** They don't use [`motion/`](../motion/), and nothing else in this repo depends on them. If you only want the toolkit, you don't need this folder: see [Clone without animation/](../README.md#showcase-films-separate-from-the-toolkit).

| Film | What's here |
|---|---|
| [first-light](first-light/): 第一次日出 / FIRST LIGHT, 106 s | Full source (WebGL + Python synth). Claude Fable 5.2, free to make anything |
| [ai-vs-captcha](ai-vs-captcha/): AI 大战验证码, 30 s | One prompt that makes the whole film |
